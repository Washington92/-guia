# Águia Gestão CRM

CRM especializado em suporte técnico e infraestrutura.

## Branches
- `main`: produção, somente alterações homologadas.
- `develop`: desenvolvimento e testes.
- `feature/*`: novas funcionalidades, integradas via pull request.

## Stack
- Backend: Python, FastAPI, SQLAlchemy; SQLite local e PostgreSQL em produção.
- Frontend: React, TypeScript e Vite.

## Módulos planejados
Clientes, contatos, oportunidades, chamados, ordens de serviço, ativos, estoque, agenda, financeiro e relatórios.

> Projeto em inicialização; nenhum deploy de produção está configurado.
